Floyd–Steinberg

The rounding error from the current dot (black) is split 7, 3, 5, 1 sixteenths to the neighbours not yet drawn.

Atkinson

Six neighbours get ⅛ each. Two eighths are simply dropped, which is why it looks punchier. Bill Atkinson used it on the first Macintosh.

Bayer matrix

Each position has its own threshold from 0 to 15. The repeating tile gives the classic crosshatch look.

Pixel art

Each colour snaps to the closest one in the palette

The process

How I built it, in order

  1. Chose browser-onlyImage conversion is pure maths on pixels, so a server would only add cost and a privacy risk.
  2. Picked three styles that share one pipelineASCII, pixel and 1‑bit all start with "shrink and read pixels". Only the drawing step differs.
  3. Used known algorithms instead of inventing themThe luminance weights (Rec. 709), Floyd–Steinberg, Atkinson and Bayer are all standard and well documented.
  4. Made the first view usefulA drawn sample image means the page never opens empty.
  5. Kept dragging smoothrequestAnimationFrame groups many slider events into one redraw.
  6. Checked what I couldA JavaScript syntax check and a check that every element id the script uses exists in the HTML.

I didn't open the app in a browser before giving it to you, so its look and real-world speed haven't been tested on many photos. Large widths with "Keep colors" on are the heaviest setting.
